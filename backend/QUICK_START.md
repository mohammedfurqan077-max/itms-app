# ITMS Backend - Quick Start Guide

## 🚀 5-Minute Setup

### Prerequisites
- Python 3.11+
- PostgreSQL 14+
- Git

### Step 1: Clone & Setup
```bash
cd backend
bash setup.sh
```

### Step 2: Configure Environment
```bash
# Edit .env file
nano .env

# Update these values:
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/itms_db
SECRET_KEY=<auto-generated-by-setup-script>
```

### Step 3: Create Database
```bash
# Using psql
createdb itms_db

# Or using SQL
psql -U postgres
CREATE DATABASE itms_db;
\q
```

### Step 4: Run Migrations
```bash
# Activate virtual environment
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate     # Windows

# Run migrations
alembic upgrade head
```

### Step 5: Start Server
```bash
uvicorn app.main:app --reload
```

### Step 6: Test
Open browser: http://localhost:8000/api/docs

## 🐳 Docker Quick Start

### One Command Setup
```bash
docker-compose up -d
```

That's it! Backend running on http://localhost:8000

### Useful Docker Commands
```bash
# View logs
docker-compose logs -f backend

# Stop services
docker-compose down

# Restart backend
docker-compose restart backend

# Access database
docker-compose exec postgres psql -U itms_user -d itms_db
```

## 📋 Common Commands

### Development
```bash
# Run server with auto-reload
uvicorn app.main:app --reload

# Run on specific port
uvicorn app.main:app --reload --port 8080

# Run with multiple workers (production)
uvicorn app.main:app --workers 4
```

### Database
```bash
# Create new migration
alembic revision --autogenerate -m "add users table"

# Apply migrations
alembic upgrade head

# Rollback one migration
alembic downgrade -1

# View migration history
alembic history
```

### Testing
```bash
# Run all tests
pytest

# Run with coverage
pytest --cov=app

# Run specific test file
pytest tests/unit/test_auth.py

# Run with verbose output
pytest -v
```

### Code Quality

## 🧪 Testing the API

### Using Swagger UI
1. Start server: `uvicorn app.main:app --reload`
2. Open: http://localhost:8000/api/docs
3. Try endpoints interactively

### Using curl
```bash

curl http://localhost:8000/health

  -H "Content-Type: application/json" \
```

## 🐛 Troubleshooting

### Database Connection Error
```bash
# Check PostgreSQL is running
pg_isready

# Check connection string in .env
DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/itms_db
```

### Import Errors
```bash
# Ensure virtual environment is activated
source venv/bin/activate

# Reinstall dependencies
pip install -r requirements.txt
```

### Migration Errors
```bash
# Reset migrations (development only!)
alembic downgrade base
alembic upgrade head

# Or drop and recreate database
dropdb itms_db
createdb itms_db
alembic upgrade head
```

### Port Already in Use
```bash
# Find process using port 8000
lsof -i :8000  # Mac/Linux
netstat -ano | findstr :8000  # Windows

# Kill process
kill -9 <PID>  # Mac/Linux
taskkill /PID <PID> /F  # Windows

# Or use different port
uvicorn app.main:app --reload --port 8080
```
